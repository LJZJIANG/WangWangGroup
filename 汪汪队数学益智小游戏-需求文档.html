汪汪队主题数学益智小游戏

产品需求文档（PRD） · 面向 5–6 岁儿童的算术与益智网页游戏
版本 v0.1（草稿） · 更新日期 2026-10-10 · 状态：待评审

1.背景与目标

5–6 岁处于幼小衔接阶段，是数感与基础运算能力形成的关键期。以“汪汪队”角色作为学习伙伴，可以把枯燥的加减法练习包装为过关救援游戏，让孩子在“帮助角色完成任务”的语境中主动练习算术；同时叠加益智小游戏以锻炼观察力、记忆力和逻辑分类能力。

本产品需要在一个网页内同时满足三方的诉求：

相关方诉求对应设计目标
儿童玩家（5–6 岁）好玩、有熟悉角色、操作简单、获得即时鼓励角色化关卡、大字大按钮、语音/动画反馈、奖励贴纸
家长能看效果、能控制时长、能查看成绩家长中心、单日时长限制、历史成绩记录
产品方一套可复用、可扩展的轻量网页游戏纯前端自包含实现，分级题库可配置

目标（可观察结果，非量化承诺）：孩子能在无家长长时间陪同下独立完成一局分级加减法练习并获得正向反馈；家长能在孩子进入游戏后看到当次练习的分级结果，并能在到达时长上限时通过“家长解锁”有效中止或延长游玩。

2.范围

最小可发布旅程（P0）

  1. 打开页面，进入角色大厅，选择角色（或直接开始）。
  2. 在「数学救援」中选择难度（简单 / 中等 / 困难），完成一局 10 题加减法，看到得分与奖励。
  3. 进入任一益智小游戏完成一局，获得贴纸奖励。
  4. 家长进入「家长中心」查看本日累计时长与历史成绩，并可调整时长上限。
  5. 当日累计游玩到达上限后，游戏被锁定，家长通过算术解锁后可选择「再玩 15 分钟」或「今日结束」。
级别内容
P0角色大厅、分级加减法（3 档）、时间锁与家长解锁、家长中心（时长设置）、历史成绩记录、基础奖励贴纸、3 个核心益智小游戏（拼图 / 记忆配对 / 找不同）、角色交互动画与提示音效
P1更多益智小游戏（迷宫 / 形状分类 / 数量排序）、完整角色配音与背景音乐、角色解锁进度、成绩周视图/图表、家长设置 PIN 解锁方式
暂不纳入多账号/多档案、在线排行榜、真实货币支付、社交分享、后台服务器与云同步（本版为纯前端本地存储）

知识产权提示

“汪汪队”（PAW Patrol）及其角色形象、名称、配色为权利方（Spin Master / Nickelodeon）持有的注册商标与版权内容。本 PRD 以“汪汪队角色”作为主题元素的前提是已获得授权或仅用于个人家庭学习用途，正式对外发布前需确认授权边界，具体处理见 第 7 节开放问题。本版需求文档默认按“个人家庭自用 / 未上架”场景编写。

3.角色与对象模型

3.1 用户角色

角色默认行为可见/可操作范围
儿童玩家进入即玩，无需登录角色大厅、数学救援、益智小游戏、自己的贴纸集；不可进入家长中心、不可修改时长、不可解除时间锁
家长通过显式入口（长按 / 算术验证）进入家长中心查看成绩、设置时长上限、解锁时间锁、重置成绩、查看隐私与说明

3.2 核心对象

对象说明关键字段
题目（Question）一道加减法题等级、算式、正确答案、干扰选项、可选图示（骨头/狗狗数）
练习回合（Round）一局 10 道题模式、等级、题目列表、当前题号、得分、正确数、开始/结束时间
小游戏局（Puzzle）一局益智小游戏类型、结果（成功/失败）、用时、得分
成绩记录（Record）一次完成的练习/小游戏结果类型、等级、得分、正确率、用时、完成日期时间
奖励贴纸（Sticker）完成的即时奖励所属角色、名称、是否已获得
时间锁状态（TimeLock）当日游玩时间账本当日累计时长、时长上限、是否锁定、剩余可延长时间
家长设置（ParentConfig）家长可调配置单日时长上限、解锁方式（算术 / PIN）、是否开启音效

4.核心流程

4.1 总体结构

区域职责
角色大厅（首页）选择角色 / 进入「数学救援」或「小游戏」入口
数学救援选择难度 → 答题 → 结算（得分 + 奖励 + 记录成绩）
益智小游戏选择小游戏 → 游玩 → 结算（贴纸 + 记录成绩）
我的贴纸展示已获得的奖励贴纸
家长中心成绩记录、时长设置、解锁入口（需验证）

4.2 一局数学救援的流程

  1. 孩子在大厅点击「数学救援」。
  2. 弹出三级难度选择卡（简单 / 中等 / 困难），每张卡显示对应角色与示例。
  3. 开始后依次呈现 10 道题；每题展示算式、可选实物图示与 3 个答案选项（大字大按钮）。
  4. 答对：播放鼓励动画 + 获得“骨头”分值；答错：温和提示 + 展示计数辅助，可再试一次，再错则进入下一题并记录。
  5. 10 题结束进入结算页：显示正确数、得星数、获得的角色贴纸，并把结果写入成绩记录。

4.3 时间锁流程

  1. 系统实时累计“当日在游戏内（数学救援 + 小游戏）的有效游玩时长”。
  2. 当累计时长到达上限（默认 30 分钟）时，当前界面立即弹出锁定层，暂停所有游戏操作。
  3. 锁定层显示汪汪队角色提示“今天玩得真棒，该休息啦～”并给出家长解锁入口。
  4. 家长点击「家长解锁」，回答一道对成人简单、对儿童较难的算术题（默认乘法，如 24 × 13 = ?）。
  5. 答对后出现两个选项：「再玩 15 分钟」或「今天先到这里」。选择前者可临时延长时间；选择后者游戏保持锁定直至次日（按本地日期判断）。

5.功能需求

以下为各模块的详细功能需求。交互密集的 P0 界面附带可点击的交互示例，示例标签与需求编号保持一致。

FR-01 主界面 / 角色大厅

目的：作为游戏入口，让孩子一眼看到熟悉角色与两大玩法入口，操作零门槛。

布局：顶部为标题与当日剩余时长提示（图标 + 圆形进度）；中部为角色列表（横向可滑动）；底部为两个大入口按钮「数学救援」「益智小游戏」，以及「我的贴纸」。右下角为低调的家长中心入口。

  • 触发：打开页面即进入大厅；无加载/登录门槛。
  • 处理规则：首次进入播放莱德欢迎语；点击角色仅做“选中 + 打招呼”反馈，不影响玩法；两个入口按钮 hover/点击有放大效果。
  • 家长中心入口：默认低调呈现（齿轮图标），点击需通过“家长验证”（见 FR-06），避免孩子误入。
  • 异常：本地存储读取失败时显示默认大厅并以空成绩启动，不阻塞进入。
FR-02 加减法练习（分级）P0

目的：通过分级加减法帮助孩子按能力阶梯练习，难度从“借助实物计数”逐步过渡到“心算”。

难度分级（题库规则）

等级数值范围出题规则示例默认角色
简单 L10–10单一加/减法，结果 ∈ [0,10]，不进位不退位，可带实物图示2+3、7−2、4+5毛毛
中等 L20–20结果 ∈ [0,20]，含进位加法，减法不退位；可带图示8+5、12−2、9+6天天
困难 L30–20含进位加法与退位减法，可选两步混合13−5、7+8、6+9−3莱德
  • 一局结构：固定 10 题，题目在对应等级题库内随机不重复抽取；数量不足时允许重复。
  • 计分规则：答对一题 +10 分；连续答对可额外获得星星鼓励（见第 6 节计分）。
  • 作答与容错：每题提供 3 个选项；首次答错不扣分，弹出计数辅助（把数字画成骨头/狗狗分步演示），允许再试一次；再次答错则记录为错误并进入下一题。
  • 结果：结算页显示正确题数、得分、获得贴纸，并写入一条成绩记录。
  • 退出/中断：中途退出（返回大厅/关闭页面）时，本局不计入成绩，但已答时间累计到当日时长。

FR-03 益智小游戏 P0 核心 / P1 扩展

目的：在算术之外，通过多种小游戏锻炼观察力、记忆力、空间与分类逻辑，增加可玩性与时长多样性。

小游戏级别角色玩法定义完成条件 / 奖励
拼图P0小砾拖动打乱的图块还原完整画面，块数随难度 3×3 / 4×4拼完整即成功，得贴纸
记忆卡片配对P0灰灰翻牌找相同图案，翻两张匹配则消除全部配对成功得贴纸
找不同P0珠珠两幅相似场景图找出 N 处不同，点中即标记全部找出得贴纸
迷宫P1路马引导角色从起点走到出口，路线需避开障碍到达出口得贴纸
形状/颜色分类P1阿奇将散落物品拖入正确分类框（颜色/形状/大小）全部正确得贴纸
数量排序P1小克按数量/大小对卡片从少到多排序排序正确得贴纸
  • 触发：大厅「益智小游戏」入口 → 选择小游戏 → 开始。
  • 处理规则：每个小游戏开局随机化内容；操作以“点击/拖拽”为主，符合 5–6 岁触控与鼠标习惯；失败可随时重来，不设惩罚。
  • 结果：成功则弹贴纸奖励并写入成绩记录（类型=对应小游戏，成绩=完成时间或步数）。
  • 异常：长时间无操作显示温和的“需要帮忙吗？”提示，不强制退出。
FR-04 奖励与贴纸集 P0

目的：用即时、正向的奖励激励孩子完成练习，形成“完成任务 → 收集贴纸”的正反馈。

  • 奖励来源：每完成一局数学救援或一个小游戏，获得与该角色/玩法对应的贴纸 1 枚；同一贴纸可重复获得并累计数量。
  • 贴纸集：「我的贴纸」页面按角色分组展示已获得贴纸（未获得显示为灰色剪影）。
  • 处理规则：奖励为本地记录，不与真实货币挂钩；不设置“扣分/失去奖励”的惩罚机制。
  • 结果：获得贴纸时播放全屏撒花/角色欢呼动画，并同步更新贴纸集计数。
FR-05 历史成绩记录 P0

目的：让家长了解孩子的练习频次、正确率与倾向，作为陪伴与引导的依据。

  • 记录范围：每次完整完成的数学救援或小游戏，各写入一条记录；中断不计入。
  • 记录字段：类型（数学救援/小游戏名）、等级、得分、正确率（正确题数/总题数）、用时、完成时间。
  • 展示：在家长中心以列表展示，支持按类型/等级筛选，按时间倒序；提供本日、累计的简单汇总（完成局数、平均正确率）。
  • 处理规则：数据存储于浏览器本地（LocalStorage），本次变更范围不包含云同步。
  • 边界：清空浏览器数据会导致记录丢失，家长中心内需说明“数据仅保存在本机”，并提供“导出/重置”入口（P1）。
FR-06 家长中心 P0

目的：提供家长专属的配置与查看入口，是时长控制和成绩查看的唯一窗口。

  • 进入验证：从大厅点击家长中心，先弹出“家长验证”算术题（同时间锁验证难度），答对方可进入；连续答错 3 次锁定入口 60 秒。
  • 可操作项：查看历史成绩与汇总、设置单日时长上限（15 / 20 / 30 / 45 / 60 分钟，默认 30）、切换解锁方式（算术题 / PIN，PIN 为 P1）、开关音效、重置成绩、查看数据存储与隐私说明。
  • 权限：家长中心的任何配置变更仅对家长可见入口生效；儿童无法绕过进入。
  • 结果：设置项修改即时保存；时长上限修改后立即作用于当日本次累计。
FR-07 时间锁与家长解锁 P0

目的：保护儿童用眼与作息，到点强制暂停，由家长决定是否继续，是产品的关键安全机制。

  • 计时口径：仅累计“进入游戏内容”的有效时长（数学救援答题页 + 各小游戏进行中）；大厅、结算页、家长中心不计入。
  • 上限：默认单日 30 分钟，家长可在家长中心调整（见 FR-06）。到达上限触发锁定。
  • 锁定行为：立即覆盖在当前界面之上，暂停/停止所有游戏计时与交互；锁定后即使刷新页面仍保持锁定（依据本地当日累计时长判断）。
  • 解锁方式（默认算术题）：出示一道对成人简单、对儿童较难的算术题（默认两位数乘法，如 24 × 13），答案需输入正确。答错可重试，连续答错 3 次进入 60 秒冷却。
  • 解锁结果：答对后提供「再玩 15 分钟」（临时延时，到达新上限再次锁定）与「今天先到这里」（保持锁定至次日，按本地日期 0 点重置）两个选项。
  • 异常：若系统时间/日期异常导致累计时长异常，保守策略为“优先锁定”，由家长在家长中心手动重置。

适用范围：本模块为跨模块统一规则，作用于角色大厅、数学救援、益智小游戏、贴纸奖励与时间锁等所有界面；各模块不再单独重复定义动画/声音规则，统一引用本模块。

处理与控制规则

  • 默认与开关：声音默认开启、音量适中；家长中心提供「音效 / 背景音乐」开关（见 FR-06）。
  • 节奏适配（5–6 岁）：动画节奏平缓（单段约 0.5–1 秒），无闪烁、无高频变化、无强烈震动，避免过度刺激；反馈以正向鼓励为主，不出现负面/恐怖形象。
  • 浏览器自动播放限制：背景音乐须在用户首次点击/交互后再播放；提示音效由用户手势触发，符合浏览器自动播放策略。
  • 异常与降级：音频资源加载失败或处于静音环境时，仅保留动画，游戏流程不阻塞、不报错；无音轨设备时提示音静默跳过。
  • 资源与授权：角色形象动画与配音受 IP 授权约束（见第 7 节 Q1 / Q2）；未获授权时以原创宠物形象与自配音替代。
